# Актуальные зависимости начальной настройки

Область: speckit-bootstrap и локальный сценарий Codex; зависимости самого продукта GRAF не меняются. Значительное изменение общего инструмента проверяется по CONTRIBUTING.md: изолированные проверки, macOS/Ubuntu, свежие upstream-версии, проверяемый выпуск.

Требования и уточнения:

- Обычная установка и обновление выбирают последние стабильные версии Spec Kit, Issue Canon и Ponytail. prerelease не выбираются автоматически.
- Python-зависимости Spec Kit заново разрешаются до самых свежих версий, совместимых с ограничениями официального пакета, даже если версия самого CLI не изменилась.
- Если каталог объявляет недоступное встроенное расширение, устанавливается наиболее новая доступная встроенная версия. Объявленная недоступная версия сообщается явно. Нельзя обходить запрет установки из каталога или подменять источник внешнего расширения.
- Обновления расширений используют штатное сохранение конфигурации и откат Spec Kit; ошибка обновления не превращается в успех.
- Ponytail включён при создании рабочей копии GRAF. Явный отказ пользователя и --frozen остаются доступными.
- Повторная настройка уже завершённой рабочей копии проверяет её зафиксированное состояние; обновление выполняется явно, а не посреди чужой работы.
- Локальные правки, проектные шаблоны, нумерация функций, инструкции и пользовательские данные сохраняются. Общая принудительная перезапись инфраструктуры запрещена.
- Автоматические проверки свежих версий выполняются ежедневно, отдельно от воспроизводимых проверок закреплённых версий.

План: обновление Python-зависимостей; ограниченная адаптация выбора доступной версии через штатный механизм обновления; включение Ponytail в поставляемом сценарии; актуализация проверочных инструментов; локальные и GitHub-проверки; выпуск SemVer и проверка установленного артефакта.

Независимая проверка требований (состояние принадлежит проверяющему):

- [x] Смысл «последняя версия» и границы совместимости определены.
- [x] Воспроизводимость и явный отказ сохранены.
- [x] Сохранение конфигурации, локальных правок и обработка ошибок определены.
- [x] Проверки охватывают реальную регрессию 1.0.0 / 1.0.1 / 1.0.2, повторное обновление Python-зависимостей, Ponytail и чистую рабочую копию.

Проверки перед выпуском: tests/ci-local.sh; pinned macOS/Ubuntu smoke; latest Spec Kit/Ponytail canary; новый и существующий GRAF в изолированных рабочих копиях; повторный doctor; опубликованный установщик и контрольная сумма. Тесты должны проверять фактическое повышение версии расширения и сохранение конфигурации, а не только код завершения.
